# USGS Water Monitoring Stations

This dashboard displays real-time streamflow data from 6 USGS monitoring stations near Jackson, Wyoming.

- **USGS Link:** https://waterdata.usgs.gov/monitoring-location/13014500/

## Data Information

- **Update Frequency:** 15-minute intervals
- **Historical Range:** Past 7 days displayed
- **Units:** Cubic feet per second (ft³/s)
- **Data Source:** USGS Water Services API
- **Data Status:** Provisional (subject to revision)

## Features

- Interactive map with clickable markers
- Real-time data visualization with line charts
- **Parameter selection:** Toggle between Flow and Temperature (where available)
- Statistics: Latest, Average, Min, Max values
- Full-screen popups on mobile devices
- Responsive design for all screen sizes

## Available Parameters

- **Streamflow:** Available at all 6 stations
- **Water Temperature:** Available at 5 stations (all except Gros Ventre River at Zenith)
